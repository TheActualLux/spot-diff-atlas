# Between Tides

A quiet, hand-drawn spot-the-difference game set across five night harbours. Find the changed details in the right-hand scene, use three hints per harbour, and take your time—the clock only adds a little pressure when a guess misses.

## Run

With Node 22, start the static server:

```sh
node serve.ts
```

Then open [http://localhost:8080](http://localhost:8080). No build step, libraries, images, fonts, or network access are needed.

## Controls

- Click or tap a change in the right scene to circle it on both panels.
- **H** or **Hint** reveals one unfound change (three hints per level).
- **R** restarts the current harbour; **Esc** pauses or resumes.
- A wrong click adds five seconds. Find every change to continue.
